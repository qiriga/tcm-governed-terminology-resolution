# Copyright and release policy

This repository separates software from data licensing. The MIT License applies only to software. Derived benchmark metadata are released only where `release_status` permits. No rights are granted here for the original terminology resource or restricted source-derived data.

Source-derived B1 main-name queries, B2 verified-alias queries, B3 controlled perturbations, and five real ambiguity examples remain blank and marked `AUTHOR_REVIEW` under the author-approved withholding decision. Fifty synthetic B4 unknown queries are `PUBLIC_SAFE`. This is a release classification, not legal advice.

Excluded from public release are complete Latin nomenclature and attribution fields, source-resource tables and documents, identifier crosswalks, full alias collections, restricted evaluation material, credentials, model assets, private notes, and unpublished working history. A pre-publication scan and human file review are mandatory.
